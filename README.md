# KN-1212: LTE MegaFon + Tailscale + AmneziaWG 3.1

Рецепт сборки для **Keenetic 4G KN-1212**, OpenWrt **25.12.6**, ramips/mt76x8.
Это исходники сборки, НЕ готовая проверенная прошивка.

## Согласованная схема

- Интернет Wi-Fi/LAN-клиентов напрямую через LTE МегаФона.
- Tailscale и AWG 3.1 только для удалённого управления, без default route для клиентов.
- Прежние SSID, пароль, LAN/DHCP и APN переносятся локально после сохранения KeeneticOS.
- В репозитории и образе нет Wi-Fi-пароля, ключей VPN, auth key Tailscale и личной адресации VPN.
- На первом старте действует стандартная конфигурация OpenWrt: Wi-Fi ещё выключен,
  LTE не настроен; служба Tailscale отключена до локальной настройки.
  Это не образ с готовыми настройками конкретного роутера.

## Сборка

GitHub: отдельный закрытый репозиторий, эти файлы в его корне.
После коммита запускается Actions → KN-1212 LTE TS AWG.
Можно также запустить Run workflow. Бесплатная квота Actions зависит от аккаунта;
платные лимиты автоматически не меняются.

Локально: свежая папка, Linux x86_64, зависимости из workflow,
затем `bash scripts/build.sh`. На самом роутере этот сценарий не запускать.

Image Builder и три пакета AWG закреплены SHA-256. Ключ AWG также закреплён.
APK проверяет подписи и зависимости. Никаких принудительных обходов ABI нет.
Официальные feeds могут обновляться: точный набор зависимостей фиксируется манифестом
и кэшем успешной сборки. Полная побитовая воспроизводимость пока не заявляется.
AWG — сторонний поставщик Slava-Shchipunov, не официальный feed OpenWrt.
В Makefile Image Builder исправляется перенос временной переменной версии между
пакетами; однострочный патч сохраняется в отчёте. Проверки подписей и ABI сохраняются.

## Результат

Только успешное выполнение всех проверок публикует артефакт `kn1212-25.12.6-lte-ts-awg-*`.
В нём factory, sysupgrade, manifest, SHA256SUMS, отчёт по размерам и кэш пакетов.
Артефакт `build-diagnostics-*` — только диагностика, он не предназначен для прошивки.

Если весь набор не помещается, сборка должна завершиться ошибкой.
Она не увеличивает разделы, не убирает Tailscale/AWG молча и не публикует урезанный
вариант под видом полной сборки. Проверяются наличие обоих образов, размер и
наличие нужных версий в manifest. Прохождение сборки не подтверждает работоспособность
на железе или достаточность оперативной памяти.

## До применения

Нужны оригинальный Recovery KN-1212, копии текущих firmware и startup-config,
фактический USB ID/режим модема и локальный доступ с Surface.
До этих проверок и отдельного подтверждения прошивку не начинать.
Включить только требуемый LTE-протокол после диагностики модема.
Настроить привычную LAN/Wi-Fi, затем TS и AWG для управления.
Проверить оба VPN отдельно и интернет клиентов при выключенных VPN.
После перезагрузки повторить проверки с внешнего подключения.

Для перехода с KeeneticOS применяется **factory через модельный OEM Recovery/TFTP**.
Sysupgrade предназначен для уже установленного OpenWrt.
Этот проект не подключается к роутеру и не запускает прошивку.
